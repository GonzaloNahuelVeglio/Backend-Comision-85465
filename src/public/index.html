Adopme API

La plataforma para unir corazones, ¡humanos y peludos!

Esta es la **API** para la gestión de adopciones de mascotas desarrollada para el curso de Backend de Coderhouse. Utilízala para interactuar con nuestra base de datos de adorables compañeros esperando un hogar.

🐶🐾 Explora nuestros Endpoints 🐾🐱

Usuarios (Users)

Gestión completa de perfiles de usuarios adoptantes y personal del refugio.

Mascotas (Pets)

Catálogo de mascotas disponibles para adopción: detalles, fotos e historial.

Adopciones (Adoptions)

Proceso y seguimiento de solicitudes de adopción, ¡uniendo familias!
